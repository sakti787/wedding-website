# Big Dream Wedding Organizer — Landing Page

Official luxury landing page concept for Big Dream Wedding Organizer (Surabaya & Sidoarjo).

## Tech Stack
- HTML5 Semantic
- Modern CSS3 (Editorial Champagne Design System)
- Vanilla JavaScript (ES6+ Interactive Budget Calculator)
- Google Fonts: Cormorant Garamond, Plus Jakarta Sans, JetBrains Mono
- Pure Static Site (Zero build step required)

## Deployment to Vercel

### Method 1: Via GitHub
1. Create a new repository on GitHub (e.g. `bigdream-wedding`).
2. Push all files in this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Big Dream luxury landing page"
   git branch -M main
   git remote add origin https://github.com/<your-username>/bigdream-wedding.git
   git push -u origin main
   ```
3. Import the repository in [Vercel](https://vercel.com/new).
4. Select "Other" framework preset (Root Directory: `./`).
5. Click **Deploy**. Your site will be live on `https://<project-name>.vercel.app` in under 30 seconds!

### Method 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
